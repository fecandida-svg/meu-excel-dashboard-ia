Planilha e Dashboard Financeiro Mensal

Arquivos incluídos

-   Planilha_Demonstrativo_Financeiro_Dashboard.xlsx — arquivo Excel com
    abas para lançamentos, resumo mensal, dashboard e instruções.
-   Dashboard_Financeiro_Mensal.html — painel visual que pode ser aberto
    em um navegador.

Como usar a planilha Excel

1.  Abra Planilha_Demonstrativo_Financeiro_Dashboard.xlsx no Microsoft
    Excel ou em um programa compatível.
2.  Entre na aba Lançamentos.
3.  Substitua os lançamentos de exemplo pelos seus dados reais.
4.  Registre uma linha para cada receita ou despesa.
5.  Na coluna Tipo, use exatamente Receita ou Despesa.
6.  Informe a data como uma data válida do Excel e o valor como número
    positivo.
7.  Consulte Resumo Mensal e Dashboard para acompanhar receitas,
    despesas, resultado e margem.

Como usar o dashboard HTML

1.  Baixe o arquivo Dashboard_Financeiro_Mensal.html.
2.  Abra-o com dois cliques ou escolha um navegador, como Chrome ou
    Edge.
3.  Preencha data, descrição, tipo e valor e clique em Adicionar.
4.  Para guardar os lançamentos feitos no painel, clique em Baixar
    lançamentos CSV.

Atenção: o dashboard HTML não salva automaticamente os dados depois que
a página é fechada. Baixe o CSV para guardar os lançamentos. Os dados da
planilha Excel e do HTML não são sincronizados entre si.

Indicadores

-   Receitas: total de entradas financeiras.
-   Despesas: total de saídas financeiras.
-   Resultado: receitas menos despesas.
-   Margem: resultado dividido pelas receitas, quando há receitas.

Observações

-   Os valores inicialmente incluídos são apenas exemplos fictícios.
    Apague-os ou substitua-os antes de usar os indicadores para decisões
    reais.
-   O resumo da planilha está preparado para os anos de 2026 e 2027.
-   Guarde cópias de segurança dos arquivos e confira os cálculos após
    substituir os exemplos.
